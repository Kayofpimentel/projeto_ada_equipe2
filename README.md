# projeto_ada_equipe2
Repositório para o projeto final do módulo 2 - turma 1680 - equipe 2
📘 Sistema de Cadastro de Clientes
Este projeto é uma aplicação simples em HTML, CSS e JavaScript para cadastro e gerenciamento de clientes. Ele foi desenvolvido com foco em organização, experiência do usuário e uso de armazenamento local do navegador.

🚀 Funcionalidades
Modal de boas‑vindas com captura do nome do usuário

Saudação personalizada usando sessionStorage

Cadastro de clientes com nome, e‑mail e plano

Validação de e‑mail

Lista de clientes renderizada dinamicamente

Exclusão individual de clientes

Filtro de busca em tempo real, ignorando acentos e maiúsculas/minúsculas

Armazenamento dos dados no localStorage

🧠 Tecnologias Utilizadas
HTML5

CSS3

JavaScript

localStorage

sessionStorage

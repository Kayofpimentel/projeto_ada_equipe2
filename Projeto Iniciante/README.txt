Projeto de cadastro de clientes - Sprint 2

Como testar:

1 - Abrir a pasta no VS Code
2 - Clicar com botão direito no index.html
3 - Abrir com Live Server
4 - Digitar o nome do operador
5 - Preencher nome, email, plano e CEP
6 - Sair do campo CEP para carregar o endereço
7 - Clicar em salvar
8 - Esperar 2 segundos
9 - Ver o cliente aparecer na lista
